# Алатау қаласының арнаулы құқықтық режимі туралы

ҚР Конституциялық Сотының 30.04.2026 № 78-НҚ нормативтік қаулысымен 27.03.2026 ҚР Парламенті қабылдаған және 31.03.2026 ҚР Президентінің қол қоюына ұсынылған «Алатау қаласының арнаулы құқықтық режимі туралы» ҚР Конституциялық заңы ҚР Конституциясына сәйкес келеді деп танылды.

> *Ескерту. Қолданысқа енгізу тәртібі осы Конституциялық заңның 90-бабында қарастырылған.*


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`ch001`](kaz/ch001.md) | 1-тарау. ЖАЛПЫ ЕРЕЖЕЛЕР |
| [`ch002`](kaz/ch002.md) | 2-тарау. АЛАТАУ ҚАЛАСЫН МЕМЛЕКЕТТІК БАСҚАРУ |
| [`ch004`](kaz/ch004.md) | `!` 4-тарау. АЛАТАУ ҚАЛАСЫНДАҒЫ ҚЫЗМЕТТІ ҚҰҚЫҚТЫҚ РЕТТЕУ |
| [`ch005`](kaz/ch005.md) | 5-тарау. ҚОРЫТЫНДЫ ЖӘНЕ ӨТПЕЛІ ЕРЕЖЕЛЕР |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
