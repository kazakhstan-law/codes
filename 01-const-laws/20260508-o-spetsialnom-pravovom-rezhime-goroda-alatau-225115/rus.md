# О специальном правовом режиме города Алатау

Нормативным постановлением Конституционного Суда РК от 30.04.2026 № 78-НП Конституционный закон РК «О специальном правовом режиме города Алатау», принятый Парламентом РК 27.03.2026 и представленный на подпись Президенту РК 31.03.2026 признан соответствующим Конституции РК.

> *Сноска. Порядок введения в действие предусмотрен статьей 90 настоящего Конституционного закона.*


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`ch001`](rus/ch001.md) | Глава 1. ОБЩИЕ ПОЛОЖЕНИЯ |
| [`ch002`](rus/ch002.md) | Глава 2. ГОСУДАРСТВЕННОЕ УПРАВЛЕНИЕ ГОРОДОМ АЛАТАУ |
| [`ch004`](rus/ch004.md) | `!` Глава 4. ПРАВОВОЕ РЕГУЛИРОВАНИЕ ДЕЯТЕЛЬНОСТИ В ГОРОДЕ АЛАТАУ |
| [`ch005`](rus/ch005.md) | Глава 5. ЗАКЛЮЧИТЕЛЬНЫЕ И ПЕРЕХОДНЫЕ ПОЛОЖЕНИЯ |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
