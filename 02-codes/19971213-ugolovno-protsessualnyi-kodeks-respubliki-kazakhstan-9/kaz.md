# Қазақстан Республикасының қылмыстық іс жүргізу кодексі


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`sec001`](kaz/sec001.md) | Жалпы бөлім |
| [`sec002`](kaz/sec002.md) | 2-бөлім. Қылмыстық процеске қатысушы мемлекеттік органдар мен тұлғалар |
| [`sec002-ch012`](kaz/sec002-ch012.md) | 12-тарау. Қылмыстық процеске қатысушы адамдардың қауіпсіздігін қамтамасыз ету |
| [`sec003`](kaz/sec003.md) | 3-бөлім. Дәлелдемелер және дәлелдеу |
| [`sec005`](kaz/sec005.md) | 5-бөлім. Қылмыстық процестегі мүліктік мәселелер |
| [`sec006`](kaz/sec006.md) | 6-бөлім. Қылмыстық іс бойынша сотқа дейінгі іс жүргізу |
| [`sec006-ch028`](kaz/sec006-ch028.md) | 28-тарау. Тану |
| [`sec006-ch037`](kaz/sec006-ch037.md) | 37-тарау. Алдын ала тергеу ісін жүргізу міндетті емес істер бойынша анықтау |
| [`sec007`](kaz/sec007.md) | 7-бөлім. Бірінші сатыдағы сотта іс жүргізу |
| [`sec007-ch044`](kaz/sec007-ch044.md) | 44-тарау. Үкім шығару |
| [`sec008`](kaz/sec008.md) | 8-бөлім. Соттың заңды күшіне енбеген үкімдері мен қаулыларын қайта қарау |
| [`sec011`](kaz/sec011.md) | 11-бөлім. Қылмыстық істердің жекелеген санаттары бойынша іс жүргізудің ерекшеліктері |
