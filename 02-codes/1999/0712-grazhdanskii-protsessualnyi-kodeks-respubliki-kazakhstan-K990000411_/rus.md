# Гражданский процессуальный кодекс Республики Казахстан

> *Сноска. См. Закон РК от 13 июля 1999 г. N 412 "О введении в действие Гражданского процессуального кодекса Республики Казахстан".*


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |

| [`sec003`](rus/sec003.md) | Раздел 3. Производство по пересмотру судебных актов |
| [`sec004`](rus/sec004.md) | Раздел 4. Восстановление утраченного судебного или исполнительного производства |
