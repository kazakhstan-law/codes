# Қазақстан Республикасының Бюджет кодексі

Осы Кодекс бюджеттiк және бюджетаралық қатынастарды реттейдi және бюджет жүйесi жұмыс iстеуiнiң, бюджет қаражатының құралуы мен пайдаланылуының негiзгi ережелерiн, принциптерi мен тетiктерiн белгiлейдi.


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`sec001`](kaz/sec001.md) | Жалпы бөлік |
| [`sec002`](kaz/sec002.md) | 2-бөлім. Бюджетаралық қатынастар және түсімдер мен шығыстарды бюджет деңгейлері арасында бөлу |
| [`sec003`](kaz/sec003.md) | 3-бөлім. Бюджеттік қатынастарды реттеу саласындағы мемлекеттік басқару |
| [`sec005`](kaz/sec005.md) | 5-бөлім. Бюджеттердің атқарылуы мен нақтылануы |
| [`sec007`](kaz/sec007.md) | 7-бөлім. Мемлекеттік қаржылық бақылау |
| [`sec010`](kaz/sec010.md) | 10-бөлім. Бюджеттік кредиттеу |
