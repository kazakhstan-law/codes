# ҚАЗАҚСТАН РЕСПУБЛИКАСЫНЫҢ ҚҰРЫЛЫС КОДЕКСІ

> *Ескерту. 01.07.2026 бастап қолданысқа енгізіледі – осы Кодекстің 148-бабының 1-тармағымен.*

Осы Кодекс Қазақстан Республикасында сәулет, қала құрылысы және құрылыс қызметін жүзеге асыруға, адам өмір сүретін және тіршілік ететін толыққанды ортаны қалыптастыруға, елді мекендерді, қонысаралық аумақтарды жоспарлауға және дамытуға, құрылыс объектілерінің пайдаланылу циклінің барлық кезеңінде олардың қауіпсіздігін қамтамасыз етуге байланысты қоғамдық қатынастарды реттейді.


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`sec001`](kaz/sec001.md) | 1-БӨЛІМ. НЕГІЗГІ ЕРЕЖЕЛЕР |
| [`sec001-ch002`](kaz/sec001-ch002.md) | 2-тарау. СӘУЛЕТ, ҚАЛА ҚҰРЫЛЫСЫ ЖӘНЕ ҚҰРЫЛЫС ҚЫЗМЕТІН ЖҮЗЕГЕ АСЫРУ КЕЗІНДЕ ӨМІР СҮРУДІҢ ЖӘНЕ ТІРШІЛІК ЕТУДІҢ ҚОЛАЙЛЫ ОРТАСЫН ҚАМТАМАСЫЗ ЕТУ |
| [`sec002`](kaz/sec002.md) | 2-БӨЛІМ. СӘУЛЕТ, ҚАЛА ҚҰРЫЛЫСЫ ЖӘНЕ ҚҰРЫЛЫС ҚЫЗМЕТІНДЕГІ МЕМЛЕКЕТТІК РЕТТЕУ |
| [`sec002-ch005`](kaz/sec002-ch005.md) | 5-тарау. СӘУЛЕТ, ҚАЛА ҚҰРЫЛЫСЫ ЖӘНЕ ҚҰРЫЛЫС ҚЫЗМЕТІНДЕГІ ТЕХНИКАЛЫҚ НОРМАЛАУ |
| [`sec002-ch006`](kaz/sec002-ch006.md) | `!` 6-тарау. СӘУЛЕТ-ҚҰРЫЛЫС БАҚЫЛАУЫ МЕН ҚАДАҒАЛАУЫ |
| [`sec002-ch007`](kaz/sec002-ch007.md) | 7-тарау. СӘУЛЕТ, ҚАЛА ҚҰРЫЛЫСЫ ЖӘНЕ ҚҰРЫЛЫС ҚЫЗМЕТІН ЦИФРЛАНДЫРУ ЖӘНЕ АҚПАРАТТЫҚ СҮЙЕМЕЛДЕУ |

| [`sec004`](kaz/sec004.md) | 4-БӨЛІМ. СӘУЛЕТ-ҚҰРЫЛЫС ЖОБАЛАУЫ |
| [`sec005`](kaz/sec005.md) | 5-БӨЛІМ. ҚҰРЫЛЫС ОБЪЕКТІЛЕРІН САЛУ (РЕКОНСТРУКЦИЯЛАУ), ПАЙДАЛАНУ ЖӘНЕ КЕЙІННЕН КӘДЕГЕ ЖАРАТУ (СҮРУ) |
| [`sec005-ch019`](kaz/sec005-ch019.md) | 19-тарау. ҚҰРЫЛЫС ОБЪЕКТІЛЕРІН ПАЙДАЛАНУ |
| [`sec006`](kaz/sec006.md) | 6-БӨЛІМ. ҚАЗАҚСТАН РЕСПУБЛИКАСЫНЫҢ СӘУЛЕТ, ҚАЛА ҚҰРЫЛЫСЫ ЖӘНЕ ҚҰРЫЛЫС ҚЫЗМЕТІ ТУРАЛЫ ЗАҢНАМАСЫН БҰЗҒАНЫ ҮШІН ЖАУАПТЫЛЫҚ. ӨТПЕЛІ ЖӘНЕ ҚОРЫТЫНДЫ ЕРЕЖЕЛЕР |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
