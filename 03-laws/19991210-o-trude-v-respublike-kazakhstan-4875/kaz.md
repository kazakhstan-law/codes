# Қазақстан Республикасындағы еңбек туралы

Осы Заң азаматтардың Қазақстан Республикасындағы еңбек бостандығына конституциялық құқығын iске асыру процесiнде туындайтын еңбек қатынастарын реттейдi.


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`ch001`](kaz/ch001.md) | 1-тарау. Жалпы ережелер |
| [`ch008`](kaz/ch008.md) | 8-тарау. Қызметкерлерге кепілдіктер беру мен өтемақы төлеу |
