# Сақтандыру қызметі туралы


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`ch001`](kaz/ch001.md) | 1-тарау. ЖАЛПЫ ЕРЕЖЕЛЕР |
| [`ch003`](kaz/ch003.md) | 3-тарау. САҚТАНДЫРУ РЫНОГЫ |
| [`ch004`](kaz/ch004.md) | 4-тарау. САҚТАНДЫРУ ДЕЛДАЛДЫҒЫ |
| [`ch006`](kaz/ch006.md) | 6-тарау. САҚТАНДЫРУ (ҚАЙТА САҚТАНДЫРУ) ҰЙЫМДАРЫН ҚҰРУ |
| [`ch006-part001`](kaz/ch006-part001.md) | `!` 21-бап. Сақтандыру (қайта сақтандыру) ұйымдарының құрылтайшылары мен акционерлерi |
| [`ch006-1`](kaz/ch006-1.md) | 6-1-тарау. Исламдық сақтандыру (қайта сақтандыру) ұйымдарын құрудың және олардың қызметінің ерекшеліктері |
| [`ch008`](kaz/ch008.md) | 8-тарау. Уәкiлеттi орган және сақтандыру қызметін мемлекеттiк реттеу, бақылау мен қадағалау |
| [`ch010`](kaz/ch010.md) | 10-тарау. Қадағалап ден қою шаралары, санкциялар және өзге де ықпал ету шаралары |
| [`ch011`](kaz/ch011.md) | 11-тарау. ҚАЙТА ҚҰРУ |
| [`ch014`](kaz/ch014.md) | 14-тарау. Дерекқорды қалыптастыру және жүргізу жөніндегі қызмет |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
