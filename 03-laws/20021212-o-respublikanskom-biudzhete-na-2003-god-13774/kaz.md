# 2003 жылға арналған Республикалық бюджет туралы

<a id="st1"></a>


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](kaz/part001.md) | 1-бап. 2003 жылға арналған республикалық бюджет 1-қосымшаға сәйкес мынадай көлемде бекітілсін: |
| [`part048`](kaz/part048.md) | `!` Қазақстан Республикасының 2003 жылға арналған республикалық бюджетi |
| [`part048-part001`](kaz/part048-part001.md) | Шикiзат секторы ұйымдарынан республикалық бюджетке есептелетiн 2003 жылға арналған салық түсiмдерiнiң көлемi |
| [`part048-part010`](kaz/part048-part010.md) | 2003 жылға арналған республикалық бюджеттің бюджеттік даму бағдарламаларының тізбесі |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
