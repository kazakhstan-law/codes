# Оңтүстiк Қазақстан облысының әкiмшiлiк-аумақтық құрылысының кейбiр мәселелерi туралы

"Қазақстан Республикасының әкiмшiлiк-аумақтық құрылысы туралы" 1993 жылғы 8 желтоқсандағы Қазақстан Республикасы Заңының 9-бабына сәйкес қаулы етемiн:

<a id="p1"></a>

1. Асықата, Жетiсай, Мақтарал аудандары таратылсын, олардың аумағында әкiмшiлiк орталығы Жетiсай қаласында болатын Мақтарал ауданы құрылсын.

<a id="p2"></a>

2. Сарыагач қаласы Сарыағаш қаласы болып аталсын.

<a id="p3"></a>

3. Келес және Сарыағаш аудандары таратылсын, олардың аумағында әкiмшiлiк орталығы Сарыағаш қаласында болатын Сарыағаш ауданы құрылсын.

<a id="p4"></a>

4. Түркiстан ауданы таратылсын.

<a id="p5"></a>

5. Қазақстан Республикасының Үкiметi осы Жарлықты iске асыру жөнiнде қажеттi шаралар қолдансын.

**Қазақстан Республикасының Президентi**
