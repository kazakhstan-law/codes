# Өскемен қаласындағы Пролетар көшесіндегі 112-пәтерлі тұрғын үйдің жобалау-сметалық құжаты мен құрылысы бітпеген 57-пәтерлі блок-секциясын беру туралы

> *Ескерту. Күші жойылды - ШҚО әкімінің 2004 жылғы 24 қыркүйектегі N 100 шешімімен.*

"Облысты әлеуметтiк-экономикалық дамытудың 1997 жылғы қорытындылары туралы" облыс әкiмiнiң 1998 жылғы 24 ақпандағы N 477-к шешiмiн орындау мақсатында және Өскемен қаласы Пролетар көшесiндегi 121-пәтерлi тұрғын үйдiң 57-пәтерлi блок-секциясының құрылысын аяқтау үшiн:

1. Құрылыс, тұрғын үй, сәулет және аумақта құрылыс салу басқармасы (Никитин Н. Л.) :

   - Пролетар көшесiндегi 121 пәтерлi тұрғын үйдiң 57-пәтерлi блоксекциясының құрылысын аяқтау жөнiнде тапсырысшы болсын;

   - мердiгерлiк ұйымды белгiлеу үшiн тендерлiк комиссияға қажеттi құжаттарды онкүндiк мерзiмде ресiмдесiн.

2. Өскемен қаласының әкiмi (Лукин А. А. ) аталған объектi бойынша жобалау-сметалық құжатты белгiленген тәртiпте бiр апта мерзiмi iшiнде құрылыс, тұрғын үй, сәулет және аумақта құрылыс салу басқармасына (Никитин Н. Л.) берсiн.

3. Облыстық қаржы басқармасы (Құрманғалиев А.ә.) тұрғын үй құрылысын аяқтау үшiн облыстық бюджеттiң бос қалдықтары есебiнен құрылыс, тұрғын үй, сәулет және аумақта құрылыс салу басқармасына (Никитин Н. Л. ) 30000, 0 мың теңге бөлсiн.

4. Осы өкiмнiң орындалуына бақылау жасау облыс әкiмiнiң орынбасары Н.Т. Носиковқа жүктелсiн.

**Шығыс Қазақстан облысының әкiмi**
