# Ақмола және Солтүстік Қазақстан облыстарының әкімшілік-аумақтық құрылысындағы өзгерістер туралы

ҒҒ"Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы" Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы Заңының 9-бабына сәйкес қаулы етемін:

<a id="p1"></a>

1. Ақмола облысының шекарасы өзгертілсін, оған Солтүстік Қазақстан облысының Еңбекшілдер, Зеренді, Щучинск аудандары мен Көкшетау қаласының аумақтары енгізілсін.

<a id="p2"></a>

2. Ақмола облысының әкімшілік орталығы Астана қаласынан Көкшетау қаласына көшірілсін.

<a id="p3"></a>

3. Қазақстан Республикасының Үкіметі осы Жарлықты іске асыру жөнінде қажетті шаралар қолдансын.

<a id="p4"></a>

4. Осы Жарлық қол қойылған күнінен бастап күшіне енеді.

**Қазақстан Республикасының Президенті**
