# Қазақстан Республикасы Ұлттық қауіпсіздік комитетінің кейбір мәселелері туралы

Қазақстан Республикасы ұлттық қауіпсіздік органдарының қызметін жетілдіру мақсатында ҚАУЛЫ ЕТЕМІН:

1. Осы Жарлыққа қосымшаға сәйкес республикалық мемлекеттік мекемелер қайта ұйымдастырылсын.

2. Қоса беріліп отырған Қазақстан Республикасы Президентінің кейбір жарлықтарына енгізілетін өзгерістер мен толықтырулар бекітілсін.

3. Қазақстан Республикасының Ұлттық қауіпсіздік комитеті Қазақстан Республикасының заңнамасында белгіленген тәртіппен осы Жарлықтан туындайтын шараларды қабылдасын.

4. Осы Жарлық қол қойылған күнінен бастап қолданысқа енгізіледі және ресми жариялануға тиіс.

**Қазақстан Республикасының Президенті**

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`an000`](kaz/an000.md) | Қайта ұйымдастырылатын республикалық мемлекеттік мекемелердің ТІЗБЕСІ |
| [`an000-part003`](kaz/an000-part003.md) | Қазақстан Республикасының Ұлттық қауіпсіздік комитеті туралы ЕРЕЖЕ |
| [`an000-part003-ch001-part001`](kaz/an000-part003-ch001-part001.md) | `!` 1-тарау. Жалпы ережелер |
| [`an000-part003-ch003`](kaz/an000-part003-ch003.md) | 3-тарау. Ұлттық қауіпсіздік комитеті бірінші басшысының мәртебесі, өкілеттіктері |
| [`an000-part004`](kaz/an000-part004.md) | Қазақстан Республикасы Ұлттық қауіпсіздік комитетінің Шекара қызметі туралы ЕРЕЖЕ |
| [`an000-part007`](kaz/an000-part007.md) | Қазақстан Республикасы Ұлттық қауіпсіздік комитетінің Авиация қызметі туралы ЕРЕЖЕ |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
