# О некоторых вопросах Комитета национальной безопасности Республики Казахстан

В целях совершенствования деятельности органов национальной безопасности Республики Казахстан ПОСТАНОВЛЯЮ:

1. Реорганизовать республиканские государственные учреждения согласно приложению к настоящему Указу.

2. Утвердить прилагаемые изменения и дополнения, которые вносятся в некоторые указы Президента Республики Казахстан.

3. Комитету национальной безопасности Республики Казахстан в установленном законодательством Республики Казахстан порядке принять меры, вытекающие из настоящего Указа.

4. Настоящий Указ вводится в действие со дня подписания и подлежит официальному опубликованию.

**Президент Республики Казахстан**

**К. Токаев**


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`an000`](rus/an000.md) | ПЕРЕЧЕНЬ реорганизуемых республиканских государственных учреждений |
| [`an000-part003`](rus/an000-part003.md) | ПОЛОЖЕНИЕ о Комитете национальной безопасности Республики Казахстан |
| [`an000-part003-ch001-part001`](rus/an000-part003-ch001-part001.md) | `!` Глава 1. Общие положения |
| [`an000-part003-ch003`](rus/an000-part003-ch003.md) | Глава 3. Статус, полномочия первого руководителя Комитета национальной безопасности |
| [`an000-part004`](rus/an000-part004.md) | ПОЛОЖЕНИЕ о Пограничной службе Комитета национальной безопасности Республики Казахстан |
| [`part003`](rus/part003.md) | ПОЛОЖЕНИЕ о Службе правительственной связи Комитета национальной безопасности Республики Казахстан |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
