# О некоторых вопросах Агентства Республики Казахстан по делам государственной службы

ПОСТАНОВЛЯЮ:

1. Реорганизовать:

   1) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Восточно-Казахстанской области» путем выделения из него республиканского государственного учреждения «Департамент Агентства Республики Казахстан по делам государственной службы по области Абай»;

   2) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Алматинской области» путем выделения из него республиканского государственного учреждения «Департамент Агентства Республики Казахстан по делам государственной службы по области Жетісу»;

   3) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Карагандинской области» путем выделения из него республиканского государственного учреждения «Департамент Агентства Республики Казахстан по делам государственной службы по области Ұлытау».

2. Внести в Указ Президента Республики Казахстан от 22 июля 2019 года № 74 «О некоторых вопросах Агентства Республики Казахстан по делам государственной службы и Агентства Республики Казахстан по противодействию коррупции (Антикоррупционной службы)» следующее изменение:

   в Положении об Агентстве Республики Казахстан по делам государственной службы, утвержденном вышеназванным Указом:

   Перечень территориальных органов Агентства изложить в следующей редакции:

   «Перечень территориальных органов Агентства

   1) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по области Абай»;

   2) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Акмолинской области»;

   3) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Актюбинской области»;

   4) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Алматинской области»;

   5) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Атырауской области»;

   6) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Западно-Казахстанской области»;

   7) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Жамбылской области»;

   8) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по области Жетісу»;

   9) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Карагандинской области»;

   10) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Костанайской области»;

   11) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Кызылординской области»;

   12) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Мангистауской области»;

   13) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Павлодарской области»;

   14) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Северо-Казахстанской области»;

   15) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Туркестанской области»;

   16) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по области Ұлытау»;

   17) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по Восточно-Казахстанской области»;

   18) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по городу Нур-Султану»;

   19) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по городу Алматы»;

   20) республиканское государственное учреждение «Департамент Агентства Республики Казахстан по делам государственной службы по городу Шымкенту».».

3. Агентству Республики Казахстан по делам государственной службы принять меры, вытекающие из настоящего Указа.

4. Настоящий Указ вводится в действие со дня его подписания.
