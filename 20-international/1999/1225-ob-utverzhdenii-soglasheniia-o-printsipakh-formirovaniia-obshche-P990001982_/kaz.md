# Тәуелсіз Мемлекеттер Достастығына қатысушы мемлекеттердің көлік саясаты саласында орта көлік кеңістігін қалыптастыру және өзара іс-қимыл принциптері жөніндегі келісімді бекіту туралы

```
Қазақстан Республикасының Үкіметі қаулы етеді:
```

<a id="para_1"></a>

1. 1997 жылғы 9 қазанда Бішкек қаласында жасалған Тәуелсіз Мемлекеттер Достастығына қатысушы мемлекеттердің көлік саясаты саласында ортақ көлік кеңістігін қалыптастыру және өзара іс-қимыл принциптері жөніндегі келісім бекітілсін.

<a id="para_2"></a>

2. Осы қаулы қол қойылған күнінен бастап күшіне енеді.

**Қазақстан Республикасының Премьер-Министрі**
