# О ратификации Меморандума о взаимопонимании между Правительством Республики Казахстан, предоставляющим ресурсы силам Организации Объединенных Наций по наблюдению за разъединением (UNDOF), и Организацией Объединенных Наций

Ратифицировать Меморандум о взаимопонимании между Правительством Республики Казахстан, предоставляющим ресурсы силам Организации Объединенных Наций по наблюдению за разъединением (UNDOF), и Организацией Объединенных Наций, совершенный в Нью-Йорке 14 февраля 2024 года.

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|

| [`ch002`](rus/ch002.md) | II. Общие условия самообеспечения |
| [`ch002_018`](rus/ch002_018.md) | `!` II. Доступ к сети Интернет |
| [`ch002_018-part001`](rus/ch002_018-part001.md) | Силы ООН по наблюдению за разъединением (UNDOF) Заявление о требованиях к роте резерва сил |
| [`ch002_018-part007`](rus/ch002_018-part007.md) | ЭКОЛОГИЧЕСКАЯ ПОЛИТИКА ДЛЯ МИРОТВОРЧЕСКИХ ОПЕРАЦИЙ И СПЕЦИАЛЬНЫХ ПОЛИТИЧЕСКИХ МИССИЙ |
| [`ch001_019`](rus/ch001_019.md) | Е.1. Общие требования |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
