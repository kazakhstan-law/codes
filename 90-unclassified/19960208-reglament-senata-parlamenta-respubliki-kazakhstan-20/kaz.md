## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`sec001`](kaz/sec001.md) | 1-тарау. Парламент Сенатының отырыстары |
| [`sec001-ch008`](kaz/sec001-ch008.md) | 8-тарау. Парламент Сенатының дербес қарауына жатқызылған мәселелерді қарау тәртібі |
| [`sec003`](kaz/sec003.md) | 3-БӨЛІМ. Парламент Сенатының органдарын құру және олардың қызметін ұйымдастыру |
