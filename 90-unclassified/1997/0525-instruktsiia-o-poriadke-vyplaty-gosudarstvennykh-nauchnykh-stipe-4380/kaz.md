# Ғылым мен техниканы дамытуға аса зор үлес қосқан ғалымдар мен дарынды жас ғалымдарға мемлекеттiк стипендиялар төлеу тәртiбi туралы НҰСҚАУЛЫҚ

<a id="p1"></a>

1. Бұл Нұсқаулық Қазақстан Республикасы Үкiметiнiң 1996 ж. 09.12 N 1501 P961501_ қаулысымен бекiтiлген мемлекеттiк ғылыми стипендиялар туралы Ереженi орындау үшiн шығарылды (ҚР ПҮАЖ-ы, 1996 ж., N 50, 488-бап).

<a id="p2"></a>

2. Мемлекеттiк ғылыми стипендиялар мөлшерi және оны алу үшiн конкурс өткiзу тәртiбi Қазақстан Республикасы Үкiметiнiң "ғылым мен техниканы дамытуға аса зор үлес қосқан ғалымдар мен мамандар және дарынды жас ғалымдарды мемлекеттiк қолдау шаралары туралы" 1996 ж. 28.08. N 1063 қаулысында белгiленген (ҚР ПҮАЖ-ы, 1996 ж., N 35, 338-бап).

<a id="p3"></a>

3. Мемлекеттiк ғылыми стипендиялар, тәртiп бойынша Ғылым министрлiгi - ғылым академиясының тиiстi мекемелер мен ұйымдар басшыларымен келiсiмi бойынша белгiленген мерзiмге стипендиаттың негiзгi жұмыс орнына керектi соманы аудару жолымен төленедi.

<a id="p4"></a>

4. Мемлекеттiк ғылыми стипендияны төлеу бiр немесе екi жылдан кейiн стипендиаттың өткен жылғы жұмысы туралы есебiн тыңдаған ғылыми (ғылыми, ғылыми-техникалық) кеңестiң тиiстi ұсынымы негiзiнде тоқтатылуы мүмкiн.

<a id="p5"></a>

5. Ғалыми (ғылыми, ғылыми-техникалық) кеңестер мемлекеттiк ғылыми стипендияны ұзарту болмаса оны төлеудi мерзiмiнен бұрын тоқтату туралы ұсынымдарын ғылым министрлiгi - Ғылым академиясына жыл сайын стипендиатқа стипендия төлене басталған айдың 15-iне дейiн тапсырады.

<a id="p6"></a>

6. Ғалыми (ғылыми, ғылыми-техникалық) кеңес стипендиат жөнiнде оң шешiм қабылдағанда кеңес мәжiлiсi хаттамасының көшiрмесi негiзiнде оған мемлекеттiк ғылыми стипендия төлеу мерзiмi өздiгiнен келесi жылға ұзартылады. Стипендиат туралы кеңес терiс ұсыным қабылдаған жағдайда ҚР Ғылым министрi - Ғылым академиясы президентiнiң тоқтату жөнiнде бұйрығы шығарылады.

<a id="p7"></a>

7. Жылма-жылғы жұмысы туралы есебi нәтижесiнде мемлекеттiк ғылыми стипендия алу құқығынан айырылған стипендиаттар оны тағайындалғанынан тиiсiнше он үшiншi немесе жиырма бесiншi айдан бастап алмайтын болады.

<a id="p8"></a>

8. Мемлекеттiк ғылыми стипендияларды төлеуге қаржы аударуды тоқтатуға басқа бiр себептер туындағанда (жұмыстан босатылғанда, қайтыс болғанда, тағы басқа жағдайда) мекеме (ұйым) басшысы ол туралы Ғылым министрлiгi - Ғылым академиясына екi апта мерзiм iшiнде жазбаша хабарлап, келесi айдан бастап стипендия төлеудi тоқтатады. Төленбей қалған стипендия Ғылым министрлiгi - Ғылым академиясына қайтарылады.

<a id="p9"></a>

9. Егер жұмыс орны өзгерiп ғылыми, ғылыми-техникалық қызмет бейiнi сақталса, стипендиат екi апталық мерзiмде Ғылым министрлiгi Ғылым академиясына қазiргi қызмет iстейтiн орнының анықтамасын қосып жазбаша хабарлайды.

<a id="p10"></a>

10. Кандидатураларын Қазақстан Республикасы Ғылым академиясының толық мүшелерi ұсынған дарынды жас ғалымдар өздерiнiң iстеген жұмыстары туралы негiзгi қызмет орнындағы ғалыми (ғылыми, ғылыми-техникалық) кеңес алдында, тәртiп бойынша, оны ұсынған академиктiң қатысуымен есеп бередi.

<a id="p11"></a>

11. Мемлекеттiк ғылыми стипендияларды төлеуге мекемелер мен ұйымдарға келесi жылдың басында қаржы аудару олар стипендиаттың есебi қорытындысы бойынша ғалыми (ғылыми-техникалық) кеңестiң ұсынымдарын Ғылым министрлiгi - Ғылым академиясына тапсырғаннан кейiн жүзеге асырылады.
